# Мешіттерді тап (Найди мечети)

Интерактивный прототип мобильной игры на память (Memory Match / Matching Pairs), посвящённой мечетям Казахстана.

---

## 1. Описание проекта

**«Мешіттерді тап»** — высокодетализированный интерактивный прототип мобильного приложения-игры. Игрок открывает карточки, находит пары одинаковых мечетей и после каждой найденной пары узнаёт название, город и один факт о мечети.

- **Назначение:** дизайн-прототип для презентации концепции, проверки визуального языка и игрового цикла до начала разработки.
- **Формат:** мобильный экран **390 × 844 px** (iPhone 14 / 13 / 12), в макете показан в корпусе устройства.
- **Языки интерфейса:** казахский и русский (переключатель ҚАЗ / РУС в шапке и в профиле).
- **Аудитория:** молодёжь и взрослые — стиль «premium Islamic app + современная мобильная игра», не детский мультфильм.

### Реализованные экраны (8)

| № | Экран | Что содержит |
|---|---|---|
| 1 | Splash / Welcome | Логотип-знак, название, слоган, индикатор загрузки, автопереход |
| 2 | Home | Приветствие, монеты, hero-блок с кнопкой «Ойынды бастау», список уровней, полоса коллекции |
| 3 | Level selection | Три уровня: Оңай / Орташа / Қиын с soft-3D бейджами, сеткой, временем и наградой |
| 4 | Main game | Статус-бар (уровень, таймер, ходы, очки), прогресс пар, сетка 3×4 / 4×4 / 4×5 с 3D-flip |
| 5 | Mosque info bottom sheet | Фото мечети, название, город, факт, начисленные очки |
| 6 | Victory / Result | Кубок, 1–3 звезды, очки / время / ходы / монеты, кнопки «Келесі деңгей», «Қайта», «Бөлісу», «Басты» |
| 7 | Leaderboard | Подиум топ-3 + список 4–10, своя строка выделена |
| 8 | Profile | Аватар, уровень и XP, статистика, монеты, «Дос шақыру», коллекция мечетей, переключатель языка |

### Игровая логика (работает, не мокап)

- Случайная раздача колоды на каждый заход; 3D-переворот карточки, сброс при несовпадении.
- Совпадение → золотое свечение + звуковая пауза-анимация → bottom sheet с информацией.
- Таймер обратного отсчёта (краснеет на последних 15 секундах), счётчик ходов, очки за пару (100 / 150 / 200 по уровню).
- Звёзды по эффективности ходов, бонус за остаток времени, начисление монет.
- Прогресс сохраняется в `localStorage`: монеты, открытые мечети, выбранный язык.
- «Бөлісу» использует `navigator.share`, при отказе — копирование в буфер обмена + тост.

### Геймификация

Экономика монет, коллекция мечетей (14 карточек, закрытые размыты и с замком), глобальный топ-10, приглашение друга (+200 монет), звёздный рейтинг уровней, XP-прогресс профиля.

## 3. Как открыть и просмотреть

### Вариант А — просто двойной клик (быстро)

Откройте **`Meshitterdi Tap.dc.html`** в браузере (Chrome, Safari, Edge или Firefox).

> ⚠️ При открытии через `file://` некоторые браузеры блокируют загрузку локальных изображений и скриптов (CORS). Если фотографии мечетей не появились или экран пустой — используйте вариант Б.

### Вариант Б — локальный сервер (рекомендуется)

Запустите из корневой папки архива одну команду:

```bash
# Python 3 — есть почти везде
python3 -m http.server 8000

# либо Node.js
npx serve .
```

Затем откройте в браузере:

```
http://localhost:8000/Meshitterdi%20Tap.dc.html
```

### Как пройти прототип

1. Splash-экран сам переходит на Home через ~2 секунды.
2. Нажмите **«Ойынды бастау»** → выберите уровень → играйте.
3. Найдите пару — снизу выедет карточка мечети, нажмите **«Жалғастыру»**.
4. Соберите все пары → откроется экран **Victory**.
5. Нижняя навигация: **Басты / Ойындар / Рейтинг / Профиль**.
6. Переключатель языка — иконка **ҚАЗ/РУС** справа в шапке Home или в конце экрана Профиль.

### Сброс прогресса

Прогресс хранится в `localStorage` под ключами `mmt:coins`, `mmt:found`, `mmt:lang`. Чтобы начать с нуля — откройте DevTools → Application → Local Storage и удалите записи `mmt:*`.

## 4. Технологии

| Технология | Роль |
|---|---|
| **HTML5 / CSS3** | Разметка и вся визуальная часть; только инлайновые стили + `@keyframes` |
| **React 18 (UMD)** | Управление состоянием прототипа — подключается рантаймом `support.js` |
| **Design Component runtime** (`support.js`) | Связывает шаблон и класс логики, отвечает за рендер |
| **Дизайн-система Industry** | Токены, типографическая дисциплина, модульная сетка, «blueprint»-мотив угловых засечек |
| **Google Fonts** | `Oswald` — заголовки, `Manrope` — основной текст, `Barlow / Barlow Condensed` — фолбэк из дизайн-системы |
| **Иконки** | Инлайновые SVG в стиле Lucide, толщина обводки 1.5–1.8 |
| **Web APIs** | `localStorage` (прогресс), `navigator.share` + `navigator.clipboard` (кнопка «Бөлісу») |

Сборка **не требуется**: нет npm, нет бандлера, нет шага компиляции. Всё работает в браузере как есть.

### Визуальный язык

- **Фон:** белый и светло-кремовый (`#F7F4EC`)
- **Основной акцент:** тёмно-зелёный (`#0E3B2E` → `#08251C`)
- **Дополнительный акцент:** золото / тёплый жёлтый (`#C9A227` → `#E7C765`)
- **Приёмы:** крупные скругления (17–48 px), мягкие тени, glassmorphism в нижней навигации, soft-3D бейджи уровней, исламский геометрический паттерн на обороте карточек, «регистрационные» угловые засечки как отсылка к дизайн-системе Industry

### Настраиваемые параметры (Tweaks)

Прототип принимает пять параметров: `startScreen`, `startLang`, `showTimer`, `accent`, `gold` — позволяют открыть нужный экран сразу или перекрасить акценты без правки кода.

## Примечания и следующие шаги

- **Названия мечетей и факты требуют проверки.** Они составлены по названиям файлов фотографий (по регионам) и по видимой архитектуре. Перед публикацией сверьте с официальными источниками.
- Фотографии — материалы, предоставленные заказчиком; права на использование нужно подтвердить отдельно.
- Данные лидерборда и профиля — демонстрационные (моковые), бэкенд не подключён.
- Возможные направления развития: звук и тактильная отдача, кнопка подсказки, ежедневные челленджи, карта Казахстана с прогрессом коллекции, серия (streak) и достижения.
